Репозиторий Unified Inbox (Email Client)
Описание
Unified Inbox – это набор консольных утилит на 8 языках программирования для управления несколькими почтовыми ящиками в одном месте. Программа имитирует работу почтового клиента с локальным хранилищем (JSON-файлы) и поддерживает:

Управление аккаунтами – добавление, переключение, удаление.

Просмотр писем – список всех писем в выбранном аккаунте с краткой информацией (отправитель, тема, дата).

Чтение писем – полный текст письма с заголовками.

Отправка писем – создание нового письма (сохраняется в папку «Отправленные»).

Удаление писем – перемещение в корзину или окончательное удаление.

Поиск – по отправителю, теме, тексту.

Экспорт – сохранение всех писем в формате MBOX или JSON.

Цветной вывод в терминале для лучшей читаемости.

Интерактивный и пакетный режимы – работа через аргументы командной строки или пошаговый диалог.

Проект создан как тестовый репозиторий для демонстрации реализации одной задачи на разных языках с использованием идиоматичных подходов.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (только стандартная библиотека)	python mail.py [команда] [аргументы]
JavaScript	Node.js 14+ (без внешних модулей)	node mail.js [команда] [аргументы]
TypeScript	Node.js + ts-node (без внешних модулей)	ts-node mail.ts [команда] [аргументы]
Go	Go 1.18+ (без внешних зависимостей)	go run mail.go [команда] [аргументы]
Java	JDK 11+ (без внешних библиотек)	javac MailClient.java && java MailClient [команда] [аргументы]
C#	.NET SDK 6.0+ (или csc)	csc MailClient.cs && MailClient.exe [команда] [аргументы]
PHP	PHP 8.0+ (без расширений)	php mail.php [команда] [аргументы]
Ruby	Ruby 2.7+ (без гемов)	ruby mail.rb [команда] [аргументы]

Команды
Команда	Описание
add-account	Добавить новый аккаунт. Требует --name и --email.
switch	Переключиться на аккаунт по --email.
list	Показать список писем в текущем аккаунте.
read	Прочитать письмо по --id.
send	Отправить новое письмо (требует --to, --subject, --body).
delete	Удалить письмо по --id.
search	Поиск писем по --query (в теме, тексте, отправителе).
export	Экспортировать все письма в файл (по умолчанию export.mbox).
accounts	Показать список всех аккаунтов.
help	Показать справку.
Опции
Опция	Описание
--name	Имя аккаунта.
--email	Email адрес.
--id	ID письма (число).
--to	Получатель.
--subject	Тема письма.
--body	Текст письма.
--query	Поисковый запрос.
--file	Имя файла для экспорта.
--data	Файл с данными (по умолчанию mailbox.json).
Примеры
bash
# Добавить аккаунт
python mail.py add-account --name "Work" --email "work@example.com"

# Переключиться на аккаунт
python mail.py switch --email "work@example.com"

# Список писем
python mail.py list

# Отправить письмо
python mail.py send --to "friend@example.com" --subject "Hello" --body "Hi, how are you?"

# Прочитать письмо с ID 1
python mail.py read --id 1

# Поиск
python mail.py search --query "meeting"

# Экспорт
python mail.py export --file backup.mbox

# Список аккаунтов
python mail.py accounts
Формат хранения
Данные хранятся в JSON-файле (по умолчанию mailbox.json) со следующей структурой:

json
{
  "accounts": [
    {
      "name": "Work",
      "email": "work@example.com",
      "messages": [
        {
          "id": 1,
          "from": "boss@example.com",
          "to": "work@example.com",
          "subject": "Meeting",
          "body": "Tomorrow at 10am",
          "date": "2025-01-01T12:00:00",
          "read": false,
          "folder": "inbox"
        }
      ],
      "next_id": 2
    }
  ],
  "current": "work@example.com"
}
Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Данные хранятся в JSON (или эквивалентном формате).

Цветной вывод (ANSI) для команд list, read, search.

Поддержка папок (входящие, отправленные, корзина) – в упрощённом варианте.

Обработка ошибок (неверный ID, отсутствие аккаунта).
